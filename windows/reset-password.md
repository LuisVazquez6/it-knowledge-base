 # How to Rest a Windows account

 ## Problem 
 User is locked out of their Window account

 ## Steps

 1. Press **Ctrl + Alt + Delete**
 2. Click **Change a Password**
 3. Enter current password, then new password twice
 4. Press the arrow button to confirm

 ## If the User is fully Locked out 
 - Contact IT admin to reset via Active Directory
 - Admin navigates to: Active Directory Users and  Computers -> Find User Right Click -> Reset Password

 ## Notes 
 - Password must be 8+ characters 
 - Must include uppercase, Number and symbols
