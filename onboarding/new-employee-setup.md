# New Employee IT Onboarding

## Overview
This guide outlines the standard IT setup process for all new employees. IT should complete the pre-arrival checklist before or on the employee's first day to ensure a smooth onboarding experience.

## Applies To
- All new full-time and part-time employees
- IT help desk technicians and system administrators

---

## Pre-Arrival Checklist (IT Completes Before Day 1)

| Task | Responsible | Done? |
|---|---|---|
| Create Active Directory user account | IT admin| [] |
| Assign user to correct security groups | IT Admin | [] |
| Set up company email account (M365/Google) | IT Admin | [] |
| Configure MFA for email and VPN | IT Admin | [] |
| Prepare and image the laptop/desktop | IT Help Desk | [] |
| Install required software | IT Help Desk | [] |
| Set up VPN access | IT Admin | [] |
| Prepare ID badge and physical access | IT/Facilities | [] |
| Send welcome email with login instructions | IT Help Desk | [] |

---

## Day 1 - Employee First Login Steps

1. Power on the assigned devices.
2. Log in which the **temporary credentials** provided by IT.
3. You will be prompted to **Change your password** - follow the password policy.
4. Set up **Multi-Factor Authentication (MFA)** using the company authenticator app.
5. Log in to **company email** and confirm access.
6. Connect access to **shared drives** and required applications.
7. Confirm access to **shared drives** and required applications.
8. Complete any mandatory **IT SECURITY AWARENESS TRAINING** assigned

---

## Standard Software Installed on All Devices

- Microsoft 365 (Word, Excel, Outlook, Teams)
- VPN Client 
- Antivirus / Endpoint Protection
- Web Browser (Chrome or Edge)
- PDF Reader
- Remote Desktop Client
- Department-specific applications *(varies by role)*

---

## Who to contact for IT HELP

| Issue  Type | Content | How |
|---|---|---|
|Password / Account lockout | IT Help Desk | Call or submit a ticket |
| Software installation | IT Help Desk | Submit a ticket |
| Hardware issues | IT Help Desk | Call or in-person |
| Security incident | IT Security Team | Call or submit a ticket |
| VPN / Remote access | IT Help Desk | Call or submit a ticket |
| Permissions / Access requests | IT Admin | Submit a ticket |

---

## Escalation
If a new employee **cannot complete login or access required systems on Day 1**, escalate immediately to **Tier 2** to avoid business disruption.

Document:
- Which systems are inaccessible 
- Exact error messages displayed
- Steps already attempted
